# JointToT 补充实验与整稿工作版 · 2026-11-24

先看[英文实验章 PDF](paper/JointToT-experiments.pdf)或[作者编辑的英文流程图](paper/figure-workflow/author/jointtot-workflow-en.svg)。下面五组记录分别回答：端云分工省多少云费、树搜索能否胜过多答几次、能否少剪掉有效分支、模型大小是否影响选枝，以及结论是否依赖判分方法。不同组的题目、模型和预算不同，不合并成一个成功率。

本仓库提供独立实验章、图源及复现材料；完整论文工作稿及其可编辑整稿包不在本仓库分发。

**经费含义。** 热启动同题 30 题的历史云端字段少 ¥0.842708，转移到较小模型的量为 875,875 tokens。若多出的本地推理支出高于这一笔，节约云费也不意味着节约总支出。上述 ¥ 均按对应旧计价代码重算，不是新账单；新裁判本地 CPU 用时不替代真实边端 GPU/网络延时测量。

## 使用和复查

- [实验章正文](paper/jointtot-experiments.tex)可直接纳入论文；如需单独编译，请用[排版入口](paper/preview.tex)。排版图 1 可用[矢量 PDF](paper/figure-workflow/author/jointtot-workflow-en.pdf)和[英文图注](paper/figure-workflow/figure.tex)。
- [生成器](paper/render.py)从各组机器可读结果排版；[证据索引](paper/evidence-index.json)记录输入和生成正文 SHA-256。以下命令从仓库根运行；快速检查不重新调用模型；详细原始记录复算见五个子目录。部分归档未随 Git 跟踪，另一台机器须提供清单相同的文件。

~~~sh
D=experiments/jointtot_202611
python3 -B "$D/paper/render.py" --check
python3 -B "$D/local_judge/verify.py" --check
# 以下三条需要各实验说明列出的原始归档；部分控制台文件不公开。
python3 -B "$D/sampling/audit.py" --check
python3 -ISB "$D/archive_game24/audit.py" --check
(cd "$D/gsm8k" && python3 -B rescore.py --check)
# 单独编译实验章（需常用 LaTeX 包）
(cd "$D/paper" && latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=tex-build preview.tex)
~~~

**本轮核验。** 五组实验的 51 项局部测试全部通过；逐题复算及来源哈希已核对。独立实验章共两页。采用作者新版图 1 的整稿共六页；整稿源码包在独立目录解压后也已编译通过。

**下一笔最有用的预算**不是 Crossword 或更多模型，而是在未见题上、同云费上限和同终局验解器下，比较「多生成一个完整解／分支」与「重排现有分支」，并跟踪到最终是否解出。当前材料适合写有正反结果的实证工作稿，还不是云端—边端端到端的非劣效研究。
