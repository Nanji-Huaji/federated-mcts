# B0 验证集：固定前沿能否保住可达候选？

深度 0 没有确定性策略比原样多保住一题。深度 1，去掉未推进槽位并按状态去重，在 118 个有活路的原始候选池上由 **51 命中变为 57**（新增 6，损失 0）。每层都只问一次“已记录的这些候选怎么选”。**这不是多解了 6 题**：深度 1 的父链始终来自 B0，不把任一策略在深度 0 的选择传下来，也没有为新前缀生成后续。

## 实测

每层各 200 题，按相同题号、相同深度配对。表中分母为**原池**有至少一条限步可达候选的题数：深度 0 为 **199/200**（3,735 条候选），深度 1 为 **118/200**（4,361 条）。所有策略共用分母。

| 规则 | 深 0：命中/199（新增/损失） | 相对原样 Δ 百分点 [95% 区间] | 深 1：命中/118（新增/损失） | 相对原样 Δ 百分点 [95% 区间] |
|---|---:|---:|---:|---:|
| 原样 stable | 131（0/0） | 基线 65.83% | 51（0/0） | 基线 43.22% |
| 只去不推进 | 131（0/0） | 0 [0, 0] | 56（5/0） | +4.24 [+0.85, +8.47] |
| 只按状态去重：max | 131（0/0） | 0 [0, 0] | 52（1/0） | +0.85 [0, +2.54] |
| 只按状态去重：sum | 131（0/0） | 0 [0, 0] | 52（1/0） | +0.85 [0, +2.54] |
| 去不推进 + 状态 max | 131（0/0） | 0 [0, 0] | 57（6/0） | +5.08 [+1.69, +9.32] |
| 只随机打破零票并列（期望） | 129.2593（8.0917/9.8324） | −0.87 [−3.95, +2.12] | 53.0947（3.9087/1.8140） | +1.78 [−0.90, +3.91] |

零票争位的前沿有 96、118 个（深 0、1），其中原池有活路的分别为 95、71 个；仅看这两组，原样命中 57、29，零票抽签期望为 55.2593、31.0947。无零票争位组各法命中同样的 74/104、22/47。深 1 的 6 个新增题号：去不推进新增 3、24、119、166、925；单独去重新增 77。旧法在该层选过 63 个未推进槽位，不等于过滤后能增加 63 个命中。

## 选择与评价如何隔离

1. [freeze.py](freeze.py) 只接受脚本中按相对路径和哈希指定的 B0 原始记录及对应 val 清单，锁定二者 SHA-256，并核验全部 200 个有序 ID。选择函数只取本层题面、原父链、原序候选和票数；日志旧选择仅用来核对。宽度 2，规则如下，少于 2 个可选项就留空，不复制或补造候选。
   - **stable**：票数降序，同票用原下标升序。**progress**：只排除逐字等于原父链的非终局候选，随后 stable。已逐条核实两层候选均为原父链或在唯一原父链上新增一步、剩余数少一个；非推进判定不使用算术可达性。只剩一个数的终态不因原样携带被过滤（这两层没有）。
   - **state_max / state_sum**：同一前沿跨父链，用完整的剩余数多重集（带符号整数排序元组，保留重复）判等。每组代表是原票最高者，票同取原下标最小者，**不是先遇到的副本**。max 按组内最高票排组，不给副本数加分；sum 作为敏感性对照，将原来投向组内各候选的票各计一次。组分相同按代表原下标打平，取前两组，不改原票、不重投。组合只在分组前去除未推进项。
   - **zero_uniform**：原样保留有票名次及正票平局。仅当还需选 k 个零票且可选零票超过 k 个时，从全部零票原下标中均匀无放回抽 k 个，不过滤、不去重。冻结的是抽样分布，故无需选抽签种子。
2. 先落盘 [frozen.jsonl](frozen.jsonl)（首行为来源信息，后 400 行为下标/抽签分布）；[score.py](score.py) 在独立进程先校验该文件的固定 hash，才做后验标签。逐行从题面验算前缀：每步消费两个实际可用的数，核实运算及剩余多重集；允许零，禁止负中间量、除零和非整除。余下每步也只能用这套规则，必须用尽所有数得到单个 24。选完深 0/1 子节点只剩 2/1 步，携带未推进父链不会退还已用层数。原池中的非法前缀仍占候选和票，只是后验不算活路（深 0/1 分别 720/834 条）。
3. “命中”指所选候选至少一条活；“新增/损失”是相对 stable 同题从 0→1 / 1→0。抽签的命中/增损均为精确期望（若固定项未命中，则命中概率为 1 − C(死零票数,k)/C(全部零票数,k)）。区间逐层、逐组对**原池有活路的题号**有放回配对重采样 10,000 次，报告平均命中差的 2.5%/97.5% 分位数，种子 20261124 + 深度；无跨层独立假设。抽签先取每题精确期望再做区间；固定题集仅重新抽签，总命中数的标准差深 0/1 为 2.8283/1.8743。区间是描述性的，未校正多重比较；样本内全同所得 [0,0] 不证明总体等价。

**真基线核对。** 两层合计 **400/400** 次 stable 选出的候选文本和顺序完全匹配日志（这两层原候选文本无重复）；单独审计原末层也为 200/200。历史终局为 **51/200 题**（**53/400** 条输出），逐条严格验算与旧奖励 0 处不同。对其他策略不报终局成绩。
